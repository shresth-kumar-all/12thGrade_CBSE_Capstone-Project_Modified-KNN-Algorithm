Overview:
This is a class 12 AI capstone project named "Strategic Tagging and Fandom Unifier" aka the STFU project. The 
project addresses the problem of having too many options for consuming content. It has highly specific user 
interface letting the user enter what type of content they want to consume and exactly what they want in that 
media by the utilising the 11 genre inputs.

Requirements:
Pandas [python -m pip install pandas]
NumPy [(installed with pandas)]
Tkinter [(standard module in python installation, but this may not be the case for an OS other than Windows)]
CustomTkinter [pip install customtkinter]
Pillow [pip install Pillow]

(the above may or may not work for an OS other than Windows. Please get all the requirements to avoid unexpected errors)
